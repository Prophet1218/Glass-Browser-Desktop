## Glass Browser Desktop 1.0.0

The first desktop version of Glass Browser for CachyOS / Arch Linux with KDE Plasma — a liquid glass browser built on Chromium (Qt WebEngine).

### Install
```
sudo pacman -U glass-browser-desktop-1.0.0-1-x86_64.pkg.tar.zst
```

### Highlights
- **Liquid glass UI** – a floating glass bar with real-time blur and edge refraction over the page content; glass menus, panels and dialogs; springy animations everywhere
- **Transparent browser** – adjustable window background opacity with KWin blur behind the window, plus optional **transparent web pages** (like Zen Browser)
- **Window buttons on the right** in the top corner, frameless window with rounded corners, drag to move, double-click to maximize
- **Chromium engine** – Google sign-in, Google passwords, My Activity and account pages work out of the box
- Tabs with live favicons, private tabs, tab overview with **Close all**, reopen closed tab, session restore
- Smart address bar with Google suggestions, history and bookmarks
- Start page with editable tiles and frequently visited sites
- Downloads panel (open file, show in folder), ad and tracker blocker, force dark pages, page translation, find in page, per-site zoom, developer tools
- Settings: theme, accent color, glass blur, refraction, animation speed, search engine, language (Hungarian / English)
- Opens links from other apps (single instance)
